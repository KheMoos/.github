# KheMoos community configuration

This repository contains the organization profile and default contribution, issue, and pull-request templates.

- `profile/README.md`: public organization profile.
- `CONTRIBUTING.md`: shared contribution guidance.
- `.github/ISSUE_TEMPLATE/`: bug and proposal templates.
- `.github/PULL_REQUEST_TEMPLATE.md`: default pull-request template.

Repository-specific templates take precedence over these defaults. The Moo repository retains its existing pull-request template.
